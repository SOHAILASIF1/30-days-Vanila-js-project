🚀 30 Days Vanilla JavaScript Challenge
📌 About This Repository

This repository contains 30 mini projects built using pure Vanilla JavaScript as part of my 30-day self-challenge.
The goal of this challenge is to strengthen my JavaScript fundamentals by building real-world projects without using any frameworks or libraries.

Each project focuses on core JavaScript concepts such as:

DOM Manipulation

Events & Event Handling

Functions & Logic Building

Arrays & Objects

Local Storage

APIs

Problem Solving

🎯 Why I’m Doing This Challenge

I am currently learning Next.js, and I strongly believe that:

Strong JavaScript fundamentals make learning frameworks much easier and more effective.

So instead of rushing into frameworks, I decided to:

Revise JavaScript deeply

Improve logical thinking

Gain confidence by building projects from scratch

Understand how things work behind the scenes

This challenge helps me think like a JavaScript developer, not just a framework user.

🗓️ Challenge Rules

⏱️ One project per day

❌ No frameworks (React, Vue, etc.)

❌ No external libraries

✅ Only HTML, CSS, and JavaScript

✅ Clean, readable, and reusable code

✅ Consistent GitHub commits

📂 Projects Included

The projects range from basic to advanced, including:

Counters & Calculators

To-Do Lists & Notes Apps

Timers & Games

API-based Apps (Weather, Quotes, Movies)

Logic-based Mini Games

Each project is placed in its own folder with clean structure.

🧠 What I’m Learning

Writing better JavaScript logic

Breaking problems into small steps

Debugging confidently

Preparing myself for Next.js & React development

🌱 What’s Next?

After completing this challenge, I’ll be:

Rebuilding some of these projects using Next.js

Applying these fundamentals to real-world applications
